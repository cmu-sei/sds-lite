Building resilient software

Good systems make the correct path obvious while retaining the flexibility experts need.

Prose supports strong text, emphasis, inline links, inline code, and keyboard input such as Command + K.

Clear information hierarchy

Headings, paragraphs, lists, quotations, code, media, and tables share predictable vertical rhythm.

Ordered work

  1. Define the outcome.
  2. Implement the smallest complete path.
    1. Preserve native semantics.
    2. Verify observable behavior.
  3. Document the interface.

Supporting principles

  • Keep interfaces small.
  • Keep related implementation local.
  • Prefer browser standards.
A design system should reduce the knowledge required to produce a consistent interface.

Terms

Module
A focused capability behind a clear interface.
Token
A named design decision shared by multiple recipes.
